## 6. Editorial evidence register to establish during implementation

For every public factual claim, track: claim ID, exact proposed text, page/section, source, status (reported / evidence received / approved / withheld), management owner, evidence date/expiry, publication permission and last review. Publish proof modules only when approval is present. An absence of metrics is acceptable; false certainty is not.

Minimum confirmation batch:

1. Legal/brand name, official logo, canonical domain and correct public contact details/recipient.
2. Exact export agency/advisory work, customs role/licence, EPT scope and any real import division.
3. Owned trucks and allowable fleet description; partner storage and any bonded-storage offer.
4. Cocoa/cashew wording; Olam role/permission; real client or credential evidence if desired.
5. Founding history/statistics, current team names/titles and photo rights.

Until confirmed, omit optional proof and broad service claims; use neutral descriptions consistent with the working brief. Verification gaps should not turn into visible placeholder statistics or badges on the production website.
